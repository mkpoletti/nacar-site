# Nácar · Medicina Dentária

Site estático (HTML, CSS e JavaScript) de uma clínica dentária fictícia em Lisboa, em português de Portugal.

- 12 páginas: Início, Sobre, Serviços, 6 páginas de serviço, Equipa, Blog e Contacto
- Hero com vídeo que avança com a rolagem, transições entre páginas e textos animados
- Formulário de contacto via FormSubmit e botão de WhatsApp (configuração em `config.js`)

Para ver localmente: `python -m http.server 4173` nesta pasta e abrir http://localhost:4173.

Os nomes, contactos e dados da clínica são fictícios.
